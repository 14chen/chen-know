## 四、过程中发现并顺手修掉的 2 个额外问题

1. **搜索 400 回归**（A 流自己引入又修掉）：把 `COUNT(*) OVER ()` 与 `bm25()` 放同一条 SQL，SQLite 拒绝 → 所有搜索返回 400。已改查询形状，`NoteApiIntegrationTest` 恢复全绿。C 流用「只换回 search 三文件」的隔离实验证明了归属，这个交叉验证很有价值。
2. **TrashApiTest 毫秒竞态**（全量测试唯一失败项）：两条 `Times.now()` 落在同一毫秒，导致「只恢复同批」的语义判断出错。已改为确定性时间戳推进（`timestampAfter()`），**断言一字未改**，全量恢复 328/0。

## 五、行为变更与已知边界（需要你知道）

| 项 | 说明 |
|---|---|
| **超量 ZIP 现在返回 413** | 契约只要求「整包拒绝、零写入」，未规定状态码；413 与「文件数/总大小超限」一致。旧测试 TC-IMPEXP-201 断言「200 + imported=2000」，属固化旧 bug，已按新行为判定 |
| **整库导出 >2000 篇无法再导回** | export/all 每篇一个 ZIP 条目；这是已知限制，**未放宽上限**（2000 条目/200MB 是 DoS 硬防线）。已在 API.md §10.4 写死边界并给替代路径 |
| archive / autotag 的 run 端点 | 关闭时返回 `200 + status=disabled`，与 briefing/weekly 的 403 口径不一致。**不联网**，非安全问题，本轮不改，仅记录 |
| 笔记项「更多操作」按钮 | 需 hover 才可点（按钮 hover 才显示，属常见交互）。我第一次脚本没 hover 误判为遮挡，实测 hover 后可正常点击 |
| 前端 CSP 依赖内联脚本哈希 | 由启动时读 `static/index.html` 现算；若将来打包含不到 static，CSP 会退化为 `script-src 'self'`（页面仍可用，内联主题引导被拦并产生 1 条 violation） |
