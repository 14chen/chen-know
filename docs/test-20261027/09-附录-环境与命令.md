## 5. 账号与首个用户规则

- 系统**没有预置账号**。空库启动时，第一个注册的人自动成为 admin（role=admin），之后注册的都是普通用户。
- 普通用户注册通常需要邀请码（由管理员生成）。
- 因此每条流都必须用**全新数据目录**，否则首人免邀请码成为管理员的逻辑会失效。

## 8. 已知坑（都是环境问题，不是产品缺陷）

| 坑 | 表现 | 绕法 |
|---|---|---|
| PowerShell ANSI 解码 | 含中文的 .ps1 里路径变乱码，实例报 Unable to access jarfile | 脚本存为 UTF-8 with BOM |
| -D 参数被拆 | java -Dkb.data-dir=... 报 ClassNotFoundException: /data-dir=... | 整个参数加引号 |
| multipart 字段名 | 用 files 得到 400「缺少上传文件 file」 | 字段名是 file |
| 简报手动 run | POST /api/briefing/run 不受 enabled 开关约束，会真实外连 | 禁止调用；只测只读端点 |
| read 工具路径 | 读 resources/schema.sql 失败 | 实际在 backend/src/main/resources/db/schema.sql |
